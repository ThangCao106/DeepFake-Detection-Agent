🔑 Claude CLI Authentication Setup

This subsystem uses the logged-in Claude CLI session. Run the following command on your server or container to complete Anthropic OAuth login:

docker compose run --rm login
  1. Run the Docker Compose command above in your terminal.
  2. Copy the Anthropic OAuth authorization link printed in console.
  3. Open the link in your browser to log into your Claude Account.
  4. Session credentials are saved to persistent volume and shared with Port 8787 automatically!
